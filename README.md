# cinematic-shot

[![skills.sh](https://skills.sh/b/1weiho/cinematic-shot)](https://skills.sh/1weiho/cinematic-shot)

https://github.com/user-attachments/assets/5eb24118-af70-4985-b558-aea73294e180

An agent skill for directing cinematic product launch films: a sequence of **hero shots**. Each shot is a steep, oblique close-up of real UI floating on a stage (a black void for dark products, a high-key studio for light ones), with a razor-thin focal plane, a slow motivated camera drift, and UI that acts on its own, hard-cut on the action. The film ends on one line of copy and a still logo.

It also shoots **stills**: the same look frozen into single photographs, for a hero image, a launch post, a social card, or a poster.

The skill covers the **look and the edit**: story, stage, shot list, shot scales, camera drift, light and grade, motion, ending, and sound direction. For stills, it covers formats, composition, the frozen moment, and the render. It works for any product and leaves the rendering stack to the agent.

## Install

```bash
npx skills add 1weiho/cinematic-shot
```

## Use

Ask your agent for a launch film, for example: "Make a cinematic launch video for our new search feature."

Or for stills: "Shoot a hero image and a social card of our new search feature."
