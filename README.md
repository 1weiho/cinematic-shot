# cinematic-shot

[![skills.sh](https://skills.sh/b/1weiho/cinematic-shot)](https://skills.sh/1weiho/cinematic-shot)

An agent skill for directing cinematic product launch films: a montage of **hero shots**. Each shot is a tight, near-frontal macro crop of real UI, with a slow camera drift and hard cuts on the beat. Every shot sits in the same dark, warmly lit room, and the film ends on one line of copy and a still logo.

The skill covers the **look and the edit**: story, shot list, shot scales, camera drift, light and grade, motion, ending, and sound direction. It works for any product and leaves the rendering stack to the agent.

## Install

```bash
npx skills add 1weiho/cinematic-shot
```

## Use

Ask your agent for a launch film, for example: "Make a cinematic launch video for our new search feature."
